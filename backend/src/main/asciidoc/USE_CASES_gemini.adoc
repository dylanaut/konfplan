== Detaillierte UseCase Beschreibungen

=== Rolle: Administrator

[cols="1,3"]
|===
| UseCase | Beschreibung / API Endpunkte

| **Veranstaltungen verwalten**
| CRUD-Operationen für Events; Import von Veranstaltungsdaten. +
`GET/POST/PUT/DELETE /api/veranstaltungen`

| **Gebäude & Räume verwalten**
| Verwaltung der Infrastruktur (Schulen, Kinos, Säle) und deren Raumkapazitäten. +
`GET/POST/PUT/DELETE /api/gebaeude` +
`GET/POST/PUT/DELETE /api/gebaeude/{id}/raeume`

| **Nutzerkonten verwalten**
| Anlage und Pflege von Administratoren, Referenten und Teilnehmern. +
`GET/POST/PUT/DELETE /api/admin/nutzer` +
`GET/POST/PUT/DELETE /api/veranstaltungen/{vid}/nutzer`

| **PlanErstellung starten**
| Ausführen des MiniZinc-Solvers zur optimalen Zuweisung von Teilnehmern zu Vorträgen basierend auf Prioritäten. +
`POST /api/veranstaltungen/{vid}/planungen`

| **Export & Ergebnisse**
| Generierung von Türschildern (PDF) und Gesamtplanungs-Exports (CSV). +
`GET /api/veranstaltungen/{vid}/export/tuerschilder` +
`GET /api/veranstaltungen/{vid}/plan/details`
|===

=== Rolle: Referent

[cols="1,3"]
|===
| UseCase | Beschreibung / API Endpunkte

| **Eigene Vorträge verwalten**
| Referenten können ihre eigenen Vorträge (Titel, Inhalt, Zielgruppe) anlegen und bearbeiten. +
`GET/POST/PUT/DELETE /api/referenten/vortraege`

| **Verfügbarkeit pflegen**
| Angabe, in welchen Zeit-Slots der Referent für Vorträge zur Verfügung steht. +
`POST /api/referenten/verfuegbarkeiten/tag`

| **Vorträge zu Events anmelden**
| Anmeldung spezifischer Vorträge für eine konkrete Veranstaltung. +
`POST /api/veranstaltungen/{vid}/vortraege/{talkId}/register`

| **Einsatzplan einsehen**
| Ansicht, wann und in welchem Raum die eigenen Vorträge stattfinden. +
`GET /api/referenten/plaene`
|===

=== Rolle: Teilnehmer

[cols="1,3"]
|===
| UseCase | Beschreibung / API Endpunkte

| **Wahlvorträge priorisieren**
| Auswahl und Gewichtung (Rang 1-10) der gewünschten Wahlvorträge. +
`GET /api/teilnehmer/priorities` +
`POST /api/teilnehmer/priorities`

| **Persönlichen Plan einsehen**
| Nach der PlanErstellung: Ansicht des verbindlichen individuellen Stundenplans. +
`GET /api/participant/plaene`

| **Referenten-Info einholen**
| Einsehen von Biografien und Profilen der Referenten zur Entscheidungsfindung. +
(Integriert in die Vortragsübersicht)
|===
