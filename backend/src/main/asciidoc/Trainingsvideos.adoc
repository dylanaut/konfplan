== Aufgabe

Wie erstelle ich eine Video, das die Nutzung der wichtigsten Funktionen adrstellt und erläutert?

2 Schritte mit Claude Code:

. Text-Skript erstellen (Konzeption)
. Video erstellen (Produktion)

.KI-Stimme (optional): Den Text aus dem Skript bei Tools wie https://elevenlabs.io/[ElevenLabs] hochladen, um eine
professionelle Sprachspur zu
generieren.

.Template für Erstellung eines Text-Skript

====
"Erstelle mir ein detailliertes Text-Skript für ein 2-minütiges Erklärvideo unserer Anwendung. Unterteile es in Tabellen-Form mit drei Spalten: 1. Sichtbare Aktion auf dem Bildschirm, 2. Gesprochener Text (Audiospur), 3. Wichtige Klick-Hinweise. Konzentriere dich auf den Kern-Workflow [Beispiel: Registrierung und Datenupload]."
====
.Template für Erstellung eines Videos mit Playwright

====
"Schreibe mir ein Playwright-Skript in JavaScript/TypeScript, das meine lokale Web-Anwendung unter https://localhost:9000 öffnet.
Das Skript soll folgende Schritte automatisch ausführen: [Schritt 1, Schritt 2, Schritt 3]. Nutze die Playwright-Option recordVideo, um die gesamte Interaktion als Video im Ordner './videos' zu speichern. Baue zwischen den Klicks künstliche Pausen (z.B. 1-2 Sekunden) ein, damit man dem Verlauf im Video gut folgen kann."
====

[NOTE]
====
Siehe auch die vorhandenen Benutzerhandbücher
====

=== Variante für Teilnehmer
Erstelle mir ein detailliertes Text-Skript für ein 2-minütiges Erklärvideo unserer Anwendung aus Sicht eines Teilnehmers.

Unterteile es in Tabellen-Form mit drei Spalten: 1. Sichtbare Aktion auf dem Bildschirm, 2. Gesprochener Text (Audiospur), 3. Wichtige Klick-Hinweise. Konzentriere dich auf den Kern-Workflow [Erstanmeldung,
Passwortvergabe, Anmeldung, Bearbeitung des Profils, evtl. Email, Eintrag der Neigungen, Bearbeitung der Verfügbarkeit,
Vergabe von Prioritäten].

Word-Ergebnis siehe link:docx/KonfPlan_Erklaervideo_Teilnehmer_Skript.docx[hier]
== Playwright

Skript zur Videoerstellung angelegt unter frontend/scripts/record-teilnehmer-demo.mjs.

.Aufruf:
[source,bash]
====
cd frontend
TEILNEHMER_LOGIN=maxi.muster TEILNEHMER_PASSWORD=Konfplan1! node scripts/record-teilnehmer-demo.mjs
====

Falls das Testkonto ein temporäres Passwort hat (Zwangswechsel bei Keycloak), zusätzlich TEILNEHMER_NEW_PASSWORD=<neues-passwort> setzen — das Skript erkennt automatisch, ob dieser Schritt überhaupt erscheint.

Was es macht (1:1 entlang des Word-Skripts): Startseite öffnen → „Anmelden" → Keycloak-Login (#username/#password) → optional Zwangs-Passwortwechsel (#password-new/#password-confirm) → Warten auf „Mein Profil" → zwei Neigungen ankreuzen + „Speichern" → „Meine Verfügbarkeit" aufklappen, zwei Slots ankreuzen + „Verfügbarkeit speichern"
  → „Vorträge & Prioritäten" aufklappen, zwei Prioritätswerte (10/8) eintragen + „Meine Prioritäten speichern".

Wichtige Details:

*  Selektoren wie input[id^="profile-neigung-"] und input.prio-input sind wörtlich aus dem tatsächlichen TeilnehmerDashboard.vue-Markup übernommen, keine Vermutungen.
*  page.on('dialog', ...) bestätigt automatisch alle alert()-Meldungen, die die App bei jedem Speichern auslöst — sonst bliebe das Skript hängen.
*  Bei einem Fehler wird ein Screenshot (error-unexpected-*.png) gespeichert, wie bei den Brevo-Skripten aus dieser Session.
*  Video landet unter ./videos/teilnehmer-demo.webm (Ordner wird von Playwright automatisch angelegt).
*  BASE_URL ist mit http://localhost:9000 vorbelegt (dein Wunsch), mit ignoreHTTPSErrors: true für ein eventuell selbstsigniertes Zertifikat.
